# Old Download Counter

This mod just brings back what the old level listing download counter looked like. Complete number is now shown (1,200,000) instead of formatted (1.2M). This mod also removes orbs from levels listing, so visually does not take any space (mostly useless tbh)

The mod uses the game's existing values, including cached saved-level counts.
Orb rewards, progress, gameplay, local editor entries, and the level detail screen are unchanged. There are no settings.
